## Mission

Make code easier to inspect, test, and maintain through small tools with explicit behavior, readable output, and documented limits.

## Projects

| Project | Scope | Status |
| --- | --- | --- |
| ast-refactor-core | JavaScript and TypeScript AST parsing and structural code smell detection | Design stage |
| cli-testgen | Reviewable unit-test scaffolds and explicit mock generation | Design stage |

The projects currently document proposed behavior. Executable releases and automated test results are not yet available. Runtime badges indicate intended technology choices, not verified compatibility.

## Tech Stack

`TypeScript` · `JavaScript` · `Node.js` · `Python` · `AST Analysis` · `Unit Testing` · `CLI Design`

Node.js and TypeScript are the initial implementation targets. Python is planned for supporting tooling.

## Principles

- Trace diagnostics to rules and source locations.
- Make generated test assumptions visible.
- Document supported syntax and known limitations.
- Publish technical claims with reproducible evidence.
