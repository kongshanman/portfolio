03 — Interfaces, not promises
ast-refactor-core — proposed analysis flow

The initial scope is syntax-aware inspection, without automatic source rewriting or whole-program semantic analysis. The following is pseudocode, not an executable API.

source = read_text("src/example.ts")
tree = parse_source(source, language="typescript", locations=true)
diagnostics = analyze(tree, rules={"max-nesting-depth": {"limit": 4}})

for diagnostic in diagnostics:
    print(diagnostic.rule, diagnostic.location, diagnostic.message)

Initial rule proposals cover nesting depth and function length. A code smell is a review signal, not proof of a defect.

cli-testgen — proposed command interface

A proposed interface for local test scaffolding. No executable CLI or installable package is available yet.

cli-testgen ./src/math.ts --framework vitest --out-dir ./tests --dry-run
Proposed parameters
OptionDefaultIntended behavior
<input>RequiredSelect the source file or directory.
--frameworkvitestSelect vitest or jest test templates.
--out-dir./testsChoose the output directory.
--mocknoneUse imports to request explicit mock stubs.
--dry-runfalsePreview planned files without writing.
--overwritefalsePermit replacing generated target files.
--helpfalseDisplay usage.
--versionfalseDisplay the release version.

Generated scaffolds require review. Expected values must come from requirements or verified examples.
